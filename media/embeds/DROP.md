# On-site embeds (keep users here)

Drop playable files — the site player loads these first (no YouTube leave).

| Folder | Formats | Use |
|--------|---------|-----|
| `video/` | `.mp4` `.webm` | Full videos / visuals |
| `audio/` | `.mp3` `.m4a` `.wav` `.ogg` | Tracks / instrumentals |
| `clips/` | short `.mp4` | Douyin/TikTok-style loops |

Name files clearly, e.g.:
- `shots-sets-it-off.mp4`
- `shots-sets-it-off.mp3`
- `shots-hook-15s.mp4`

Then add/update entries in `/media/manifest.json`.
