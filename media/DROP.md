# Media Drop Zone (HQ)

Drop high-quality media here. Site can reference paths under `/media/`.

| Folder | Put |
|--------|-----|
| `images/hero/` | Full-bleed hero stills |
| `images/album/` | Album / single covers |
| `images/hq/` | Print-quality stills |
| `images/thumbnails/` | Small previews |
| `images/og/` | Open Graph / social share |
| `audio/tracks/` | Full tracks / instrumentals |
| `audio/stems/` | Stem packs |
| `audio/samples/` | Short clips / tags |
| `video/clips/` | Short vertical / square clips |
| `video/full/` | Full videos |
| `video/promo/` | Promo / trailer cuts |
| `gifs/` | Reaction / loop GIFs |
