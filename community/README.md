# Community cards

Use **Community Card Studio** (`/community-card.html`) to stamp early supporters:

1. Drop NFT / avatar (or paste)
2. Type `@username`
3. Optional badge: `Early Supporter`
4. Download PNG · share on X / IG / TikTok

Edit `roster.json` to keep the early-supporter chip list current.
Drop finished exports into `cards/` if you want them in-repo.
