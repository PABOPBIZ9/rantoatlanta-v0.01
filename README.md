# RanToAtlanta v0.01

Genius-inspired lyrics archive for **Hot Boys — Shots Set’s It Off** (*Get It How U Live!!*, 1997).

## Live

**https://pabopbiz9.github.io/rantoatlanta-v0.01/**

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Structure

| Path | Purpose |
|------|---------|
| `index.html` | Lyrics page |
| `assets/` | CSS, JS, images |
| `brand/` | Drop logos / promo kits |
| `media/` | Drop audio / video |

## Notes

Fan archive UI inspired by the Genius lyrics layout. Not affiliated with Genius, Cash Money Records, or the Hot Boys.
Clicking the **RanToAtlanta** wordmark refreshes the page.

## Deploy

GitHub Pages via Actions on `main`.
